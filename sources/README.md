# 本地原始资料

此目录保存论文 PDF、必要的作者源文件、提取文本和本地阅读索引。除本说明外，目录内容由 `.gitignore` 排除，不随仓库发布。

来源元数据维护在 `references/catalog.yaml`。每项资料记录公开链接、使用版本、下载地址、相对路径、下载状态及实际文件的 SHA-256。公开正文链接到原始来源；下载成功的文件由本地索引提供相对链接。

下载失败的条目保留原因，不能生成指向不存在文件的下载链接。PDF 与网页提取文本分别标记，提取文本不充作原始 PDF。

当前已保存作者英文字幕；必备论文 PDF 与引用原图待下载。执行 `python3 scripts/sources.py` 可重新生成 `sources/INDEX.md`，该命令只检查已有文件。下载命令及限制见[来源记录说明](../references/README.md)。

维护原则见 [引用与证据规范](../CONTRIBUTING.md)。
