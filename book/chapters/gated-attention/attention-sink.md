# 5.3 输出调节与 Attention Sink

输出 Gate 将“从哪里读取”与“传递多大幅度的结果”分开。研究这种调节时，一个具体观察对象是 Attention Sink。Attention Sink 指某些位置持续获得较高权重，即使其文本内容与当前预测缺乏明显关联。StreamingLLM 在所研究模型中观察到初始位置的这一现象，并通过替换初始 Token、移除或保留其 KV 检查影响。[Xiao et al.，§3.1](https://arxiv.org/html/2309.17453v4)

## 权重归一化与输出幅度

对一个 Query，Softmax 权重满足 $$a_j\geq0$$ 且 $$\sum_j a_j=1$$。它分配相对权重，但没有单独的标量控制整组汇总结果的幅度。若使用 Headwise 输出 Gate $$g\in(0,1)$$：

$$
g\sum_j a_jv_j=\sum_j(ga_j)v_j,\qquad \sum_jga_j=g.
$$

右边是相同输出的代数重写。原 Attention 权重仍是 $$a_j$$，并未被重新计算；$$ga_j$$ 是加入输出幅度后的有效系数。

Elementwise Gate 对每个特征维度使用不同系数，通常不能用一套标量权重同时表示所有维度。比较可视化时，应说明画的是原始 Softmax 权重、Gate 值，还是经过调节的输出。

## 小系数与稀疏执行

有限输入的数学 Sigmoid 值严格位于 0 与 1 之间。Gate 分布接近零，可以削弱输出，但不会自动删除某个 Key 位置或跳过已经完成的 SDPA。

若实现希望跳过 Head 或位置，需要额外的选择规则、阈值或稀疏 kernel，并核查由此带来的数值与质量变化。这里的特征抑制与第七章减少位置连接的 Sparse Attention 属于不同操作。

保留 Sink KV 以稳定已有模型，是推理缓存策略；训练输出 Gate 以改变模型行为，是结构与训练策略。它们的效果应在相应设置下评估，缓存处理将在第八章展开。
