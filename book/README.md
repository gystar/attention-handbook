# 大模型 Attention：原理、演进与优化

本书围绕 Transformer 与大模型中的 Attention，解释方法为何出现、改变了什么，以及如何比较其能力与计算成本。

第 1 章建立技术地图；后续三篇分别讨论原理与结构改进、计算优化与 KV Cache、Linear Attention 与 Hybrid Architectures。阅读需要线性代数、概率和神经网络的基本知识。
