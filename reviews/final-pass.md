## 第二章

### 技术与跨章核查

- Q/K 维度同为 d_k，Value 为 d_v；Cross-Attention 的两种输入维度和序列长度独立定义。
- Causal Mask 使用完整序列位置；带缓存时 j≤p+i，未把矩形 Mask 当作左上角三角矩阵。
- 输入与训练目标错位、Padding Key 与 Query/loss 的处理、全 Mask 行和 dropout 行和限制均保留。
- Output Projection 的分块求和式与 Concat 形状一致；标准 MHA 参数量计数明确使用 hd_h=d_model。
- 缓存等价限定相同参数、前缀、位置处理及确定性计算，与第三章动态频率条件及第八章前缀复用一致。
- 成本表区分前向核心、投影、显式中间矩阵和 KV，有效因果配对数与数量级一致。

## 第三章

### 目录与结构

顺序需求 → Absolute/Relative → RoPE/ALiBi → 扩展方法 → 评估。3.1 先区分内容、Mask 与位置，3.4 先定义长度及扩展因子，再解释不同频率变换，避免将方法列为无关联清单。

### 技术与跨章核查

- 无 Mask 的置换等变推导不推广到固定 Causal Mask。
- Sinusoidal 的维度对顺序为 sin/cos，相应平移矩阵符号正确；RoPE 的二维旋转采用列向量约定，相对项为 R_(j−i)。
- RoPE 的共同平移性质限定固定内容向量，不推断整模型移位不变或点积随距离单调下降。
- T5 Bias 不强加统一的内容缩放约定；ALiBi 偏置作用于缩放后的内容分数。
- PI 位置与频率缩放等价；NTK-aware 的 d>2 条件、端点频率、YaRN 插值系数与温度变换一致。
- Dynamic Scaling 分开说明旋转规则不一致与深层旧隐藏状态问题，未声称重新旋转 Key 即可恢复整模型等价。
- 长度泛化区分预训练、扩展训练及测试长度；PPL 明确上下文与计分集合，LongBench 长度单位不冒充 Token 数。

实际执行 `python3 scripts/verify_position_encoding.py`，退出码 0。13 项代数检查最大误差 2.22e-16；四个反例差异分别约 0.6323、2.0、0.1618、0.01827，均符合脚本断言。只验证代数及构造模型，不验证长上下文任务能力。

## 第四、五章

### 目录与结构

### 技术与来源核查

- KV 缓存字节数使用 KV Head 数，常规逐 Head Attention FLOPs 使用 Query Head 数；MLA 的容量不再乘 Key/Value 的系数 2。
- MHA→GQA 的投影均值不能保留非线性 Attention 输出；MLA 的展开与 Latent 路径比较同一个已定义模型。
- MLA 重排从实际送入 Up-projection 的 Latent 开始，不跨越 RMSNorm；Decoupled RoPE 分数先相加后归一化，缩放仍由原始拼接维度决定。
- 第五章表 5-5 的 7.499/7.404、50.21/51.15，本轮重新打开 2505.06708v1 §3.2.2/Table 2 核对；28 层、1.7B、400B、batch 1024、学习率 4e-3 与 FFN 宽度调整条件均一致。
- 固定一次前向时，输出 Gate 不反向改变已经计算的 Softmax 权重；训练后的 Sink 变化与单次计算的代数性质分别说明。

实际运行 `verify_kv_representations.py` 与 `verify_gated_attention.py`，均退出 0。前者六项等式检查最大误差 1.11e-16；错误 Latent 缩放反例差异约 0.02077。后者四项等式检查误差为 0，Value/Output Gate 差异约 0.06，动态 Gate 固定线性映射反例差异约 0.29948。均未验证训练质量或 GPU 性能。

### 第九章结构与数学

六节按核分解、因果递推、衰减、误差修正、并行计算和容量评估展开。区分 ELU 核替换、随机特征近似与固定核内等价重排；不将未归一化 GLA 读取解释为概率权重。

- 正随机特征的高斯矩母函数推导与缩放一致，核估计无偏不推广到归一化输出无偏。
- 因果递推先写入再读取，Packed Sequence 边界与连续 Chunk 状态传递分别说明。
- GLA 状态为 Key×Value，逐行 Gate 与累乘范围一致；DeltaNet 的修正依赖当前 Key 范数，Gated DeltaNet 误差基于衰减后状态。

- 容量结论限定同一固定状态的线性读取或有限比特精确检索，未推断完整模型只能处理 d_k 个 Token。
