## 本轮修订与证据

6.4 在 FA2—FA4 的调度说明后增加“低精度矩阵乘法”，与其标题的硬件适配范围一致。采用 [SageAttention 2410.02367v1](https://arxiv.org/html/2410.02367v1) §4.1—4.4、Table 6 中 SAGEAttn-B 的具体路径：Q/K INT8、Online Softmax 保持高精度、PV 使用 FP16 输入与 FP16 矩阵乘法累加器。没有泛称所有中间量均为 INT8，也没有将 PV 累加器精度推广到全程输出累积。

共享 Key 平移由 Softmax 行平移不变性直接推出：对每个 Query，所有有效 Key 减去同一个向量会从有效分数中减去同一标量。此结论要求同一行至少有一个有效位置，并且平移向量在其 Key 间相同；后续量化不享有精确不变性。实际执行 Python float64 算例：seed=64，100 组，长度 2—19、维度 1—11，Causal 有效前缀；最大误差 4.44e-16。此检查只验证平移关系，不验证低精度 kernel、模型质量或速度。

原论文 HTML 中部分 Online Softmax 更新式存在与本书合并推导不一致的符号和因子，本轮不转录其伪代码；分块递推继续以第六章已验证公式为准。此处引用仅用于精度路径与 Key 平移设计。

## CV-02 修订复查

本轮核读 [Linformer 2006.04768v3 §4、§5.1](https://arxiv.org/html/2006.04768v3#S4)，将“通道压缩与序列压缩”放入 4.5：先比较保存对象，再进入执行性能，保留第四章以 MQA/GQA/MLA 为主体的结构。9.1 引言改为明确列举 MHA/MQA/GQA/MLA，避免将新增 Linformer 也概括为逐位置读取。

- 原文 §4 的 E/F 尺寸文字与乘法方向存在转置不一致；本书按 EK、FV 的乘法统一为 r×N。K 为 N×d_h、V 为 N×d_v，压缩后为 r×d_h、r×d_v；QK̃ᵀ 为 N×r，输出 N×d_v。
- EK/FV 与后续两次乘法合计 O(Nr(d_h+d_v))，省略常数项并计入序列投影；线性结论明确固定 r 和通道维度，不声称全部 Attention 天然低秩。
- 因果反例为本文构造：固定首位置 v1=0，分别取未来 v2=2、4，单个平均 Value 条目使首行输出为 1、2。已实际执行 Python 算例。Mask 仅决定是否读取压缩条目，无法分离该条目内部的未来成分。该反例不排除另行设计的因果压缩方法。
- 原论文预训练任务核对为 MLM，不写成自回归 LLM 训练证据；未转录性能数字或近似定理。
- 表达专项逐段复查：三种压缩对象用短列表比较；数学形状、固定维度和因果限制均保留。无新增空泛总结，图表编号不变。新正文与来源入口、catalog、GOAL 数量同步；目标 GitBook 呈现仍未检查。
