### 数学检查与实际结果

Python 3.12.3，标准库，随机 seed 20261026，容差 1e-11。13 项数值恒等关系均通过，最大误差约 2.22e-16：

- 无 Mask 的置换等变、Sinusoidal 固定偏移变换。
- RoPE 相对点积、共同平移、范数保持、图 3-3 的两组 1/2 算例。
- PI 位置缩放与频率缩放等价；NTK-aware base 变换与逐维比值等价、最高/最低频端点。
- 一致维度置换下的相邻配对与分半配对、温度与 Q/K 同时缩放。
- 固定 RoPE 下完整计算与逐步缓存一致；单层缓存 Key 反旋转后按新规则旋转，与直接新规则计算一致。

另外，ALiBi 偏置与等内容分数下的权重排序通过。四个反例均产生明确差异：固定 Causal Mask 下的置换差异约 0.6323；RoPE 点积的非单调反例差异 2；新旧频率混用的缓存输出差异约 0.1618；两层 Attention 在重旋转后仍保留旧隐藏状态的输出差异约 0.01827。

这些反例使用人工构造的输入和参数，仅验证数学限制，没有训练或运行完整语言模型。

公式人工复核覆盖：Shaw 的分数与 Value 加项、T5 bias 的维度、RoPE 的 j−i 符号、PI 的开区间、YaRN 过渡函数端点与温度、PPL 的目标计数与条件。图 3-6 参数与生成脚本一致，图中不含 Attention Scaling 温度。

本地结构检查覆盖 68 个 Markdown 文件、305 个本地文件链接、28 个导航入口；另行核对 118 个整页标题链接，未发现名称不一致。图 3-1—3-7、表 3-1—3-8 编号连续。第二章数学脚本和既有示例脚本均通过；公式括号检查不代替 GitBook 渲染检查。
