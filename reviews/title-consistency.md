# 页面名称一致性复查

2026-10-19，作者自查。按用户要求撤销侧栏简称：页面名称以 Markdown 一级标题为唯一依据，统一 SUMMARY、阅读首页、跨章链接及仓库首页的 90 处链接文字。主题分组、链接目标、章节顺序和正文标题不变。

写作规范新增名称一致性要求。旧 Review 保留为历史记录，其关于侧栏简称的方案已由本次修改取代。当前版本见 [title-consistency.sha256](title-consistency.sha256)。

实际验证：逐个比对书稿及根目录文档中指向书内整页的链接文字与目标一级标题；比对修改前后的链接目标序列；执行本地结构检查及 git diff --check。上述检查通过。GitBook 同步后的页面标题与导航显示尚待验证，不将本地检查等同于线上验收。
