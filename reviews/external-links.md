# 全书外部链接核查

## 范围与版本

2026-10-26，作者自查。提取 `book/**/*.md` 中的 HTTPS 链接与资源地址，覆盖正文、导航及附录；不包含仅在 catalog 中出现的下载地址。本轮检查可访问性，不重复判定全部引用是否支持技术论述。

逐项结果与引用文件见 [核查数据](external-links-checks.json)，对应版本见 [校验值清单](external-links.sha256)。本轮未修改书稿。

## 检查方式与结果

将同一页面的多个 fragment 合并后，共 179 个页面或资源地址，原始不同 URL 为 254 个，其中 75 个带 fragment。使用网页工具访问公开页面、PDF 与图片，使用 GitHub connector 读取仓库内 LICENSE 和字幕文件。

| 检查项 | 实际结果 | 判定 |
| --- | --- | --- |
| 页面或 PDF 内容返回 | 170 个地址返回 HTML、PDF 文本或仓库文件内容；页面标题与目标资料对应 | 已完成本轮可访问性检查 |
| PDF 解析 | LongBench、SageAttention、StreamingLLM 的三个 PDF 超出网页工具内容大小限制；其 HTML 正文可访问 | PDF 待核查，不据此判为死链 |
| 图片资源 | 三个 arXiv PNG 只返回资源引用；一个 Jay Alammar GIF 返回格式不支持 | 显示与文件核验待完成 |
| 视频 | YouTube 主链接仅返回标题与页面框架，带时间参数的链接返回 Cache miss；作者教程页及字幕可访问 | 播放及时间定位待核查 |
| fragment | 75 个带 fragment 的 URL，其基础页面可访问；工具文本输出未提供可充分验证的 DOM id 或浏览器定位结果 | 锚点待核查 |
| 本地归档 | 本轮未取得新的 PDF 或图片文件，不能用网页解析文本替代原始文件 | 待完成 |
| GitBook 呈现 | 未执行当前工作树的目标页面预览 | 待完成 |

网页工具可能使用缓存，本记录的检查日期是访问工具的日期；不将其表述为所有站点在该时刻均返回 HTTP 200。结果 `content_returned` 只表示取回了对应内容，不包含浏览器跳转、交互和文件完整性验收。

## 下载条件复查

实际执行两次只读检查：

- `curl -I --max-time 10 https://arxiv.org/pdf/1706.03762` 返回 exit 7，无法连接配置的代理 `127.0.0.1:7897`。
- `curl --noproxy '*' -I --max-time 10 https://arxiv.org/pdf/1706.03762` 返回 exit 6，无法解析 `arxiv.org`。此参数仅影响该命令，没有更改环境代理或系统配置。

这两次结果说明当前终端访问路径不可用，不能据此断言用户机器上的代理整体失效。网页工具可以访问资料，但本次没有取得可写入本地的原始 PDF 字节。

## 目录与表达核查

本轮仅新增审阅记录，不改变章节结构、小标题、正文、图表或来源版本。记录区分网页内容返回、原始文件归档、锚点与渲染检查，未将工具限制写成资料失效，也未将基础页面可访问写成精确定位已通过。已逐段检查状态表与结论，保留影响验收范围的限制；无新增技术或性能结论。
